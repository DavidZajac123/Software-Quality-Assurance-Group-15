# Software Quality Assurance Final Project Group 15

CSCI 3060U - Software Quality Assurance  
Fall 2026  
Group 15

This repository contains the group project for the Digital Games Distribution System.

The project is completed in multiple phases throughout the semester.

## Phase 1 - Front End Requirements

Phase 1 contains the requirements test suite for the Front End.

The Phase 1 work includes:

- requirements test-case documentation
- test input files
- expected terminal outputs
- expected Daily Transaction File outputs
- shared test data
- test organization and execution planning
- expected/actual result organization
- AI usage documentation

See the `phase1/` directory for the Phase 1 deliverables.

## AI Usage

Generative AI usage documentation is stored in the `ai_usage/` directory in accordance with the course requirements.
