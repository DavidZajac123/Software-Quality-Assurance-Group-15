Refund Requirements Tests

This folder contains the Phase 1 requirements tests for the refund transaction.

Number of test cases: 13

These tests cover admin-only access, valid and invalid buyer/seller usernames, blank input, nonnumeric refund amounts, balance transfers, sufficient and insufficient seller credit, and zero or negative refund amounts.

File naming convention:

refund_XX_input.txt
refund_XX_expected.txt
refund_XX_dtf_expected.txt
