Delete Requirements Tests

This folder contains the Phase 1 requirements tests for the delete transaction.

Number of test cases: 7

These tests cover valid user deletion, admin-only access, nonexistent users, attempts to delete the currently logged-in user, deleted-user available inventory, blank usernames, and the documented group assumption for Game Collection entries owned by a deleted user.

File naming convention:
delete_XX_input.txt
delete_XX_expected.txt
delete_XX_dtf_expected.txt
