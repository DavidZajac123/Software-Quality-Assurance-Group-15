Create Requirements Tests

This folder contains the Phase 1 requirements tests for the create transaction.

Number of test cases: 11

These tests cover creation of all supported user types, admin-only access, duplicate usernames, username length boundaries, invalid user types, blank usernames, and the confirmed starting credit balance for newly created users.

File naming convention:

create_XX_input.txt
create_XX_expected.txt
create_XX_dtf_expected.txt
