Actual Test Outputs

This folder will contain the actual outputs generated when requirements tests are executed against the Front End.

Expected file naming examples:

buy_01_actual.txt
buy_01_dtf_actual.txt

sell_03_actual.txt
sell_03_dtf_actual.txt

The actual terminal output will be compared against the corresponding *_expected.txt file.

The generated Daily Transaction File will be compared against the corresponding *_dtf_expected.txt file.

This folder remains empty during Phase 1 because the Front End has not yet been implemented.
