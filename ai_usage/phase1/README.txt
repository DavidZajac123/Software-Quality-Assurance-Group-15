Phase 1 AI Usage

Generative AI (ChatGPT) was used during Phase 1 of the CSCI 3060U Software Quality Assurance project.

AI was used to assist with:

- interpreting and reviewing the Front End requirements;
- identifying requirement ambiguities and inconsistencies;
- developing and reviewing requirements test cases;
- identifying boundary, invalid-input, permission, and transaction-output test cases;
- preparing expected Daily Transaction File outputs according to the required record formats;
- checking fixed-width field lengths, padding, transaction codes, and monetary formatting;
- developing shared test data and test-specific fixture data;
- incorporating client/TA clarifications into the test suite;
- reviewing the consistency of test inputs, expected outputs, shared data, and test-specific fixtures;

AI was not used to implement the Front End program during Phase 1, as implementation is outside the scope of this phase.

All AI-assisted work was reviewed against the project requirements and the client/TA clarifications before being incorporated into the submitted materials.
